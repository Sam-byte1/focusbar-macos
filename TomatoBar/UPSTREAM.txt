Modifications: single-session focus timer, fixed-width menu bar progress image,
Chinese popover, continuous-clock pause/resume, native notifications and hotkey,
and a Command Line Tools build path. Version 2 adds a shared independent window,
custom focus types, local versioned history/checkpoints, actual-time statistics,
Swift Charts dashboards, filtered CSV export and configuration UI. Sleep pauses
sessions; app absence is never inferred as focus time. Original Xcode project
retained and adjusted.
